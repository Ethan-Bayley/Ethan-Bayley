## About me

- Solo competitor on VEX Robotics team **4613R (Barker Redbacks)**
- Qualified to **VEX Worlds** in both of my previous seasons
- Student at Barker College
- Localisation and odometry are where I go deepest
- I design, print and program my own robots, from CAD to competition code
- Currently building for the **VEX Override** season (2026-2027)
